Mobile Magnetometer
v1.0.0 Latest
Real-time magnetic field telemetry  ·  Android · Windows · Linux

Reads raw X / Y / Z values from the phone's hardware magnetometer in µT, streams them over WebSocket to a PC dashboard, and records them to CSV. Designed for precision measurements with Helmholtz coils and similar lab equipment.

Features

  • Raw X / Y / Z field readings in µT at up to 20 Hz
  • Live scrolling chart with per-axis colour coding and pause/resume
  • Zero / un-zero calibration — subtracts ambient baseline
  • CSV recording with start / stop control and event markers
  • Recording management: view, download, and delete from the dashboard
  • Phone IP saved for automatic reconnect on next launch

Getting started

  1. 1
    Install the PC app. Run Mobile-Magnetometer-Setup.exe (Windows) or the .AppImage / .deb (Linux) and launch Mobile Magnetometer. The server starts automatically and prints the local IP address.
  2. 2
    Install the Android app. Transfer Mobile-Magnetometer.apk to your phone and tap it to install.
    Enable Install unknown apps in Android Settings for your file manager before installing.
  3. 3
    Connect. Open the app on the phone → tap PC in the header → enter the PC's local IP (e.g. 192.168.1.45). Both devices must be on the same local network.
  4. 4
    Record. The status badge changes to LINKED and data starts streaming. Click ▶ REC in the dashboard to start a CSV recording.
