First Run

  1. Run Mobile-Magnetometer-Setup.exe on the PC and complete the installer, then launch Mobile Magnetometer from the Start Menu or Desktop. The server starts automatically and shows the PC's local IP address.
  2. Transfer Mobile-Magnetometer.apk to the Android phone (USB cable, cloud drive, AirDrop equivalent, etc.) and tap it to install. If prompted, allow installation from unknown sources for your file manager app.
  3. Open Mobile Magnetometer on the phone → tap the PC button in the header → enter the PC's local IP address (e.g. 192.168.1.45). Both devices must be on the same Wi-Fi network.
  4. The status badge changes to LINKED and the magnetometer starts streaming. Live values and the chart appear on both screens. The IP is saved automatically for future sessions.
  5. Click ▶ REC in the PC dashboard to start a CSV recording. Click ■ STOP when done. Download the file from the Saved Recordings panel on the right.
